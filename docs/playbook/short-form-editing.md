# Short-form talking-head editing brief (Ultimate Editors)

Source: "Prompts List.docx", shared by the user (Drive file 1T28n-QfyyjrKGUHg95MaI5j4XDVERWw6).

That doc is only the master prompt. The full brief is a separate visual PDF/board it calls "the link below", and it
was NOT included. Ask the user for that PDF/board before claiming to follow its visual specifics (exact fonts,
colours, inspiration images).

## The brief has six panels; use them in this order
1. **Captions (top left)**
   - Two type families: a **sans** (main lines) and a **script** (emotional/accent words).
   - The board defines font placement, colour and animation. Follow it exactly.
2. **Caption inspiration board (top right)**
   - Reference it every time captions are made.
3. **Hook document (under captions): hook psychology**
   - Keep the speaker on screen during the hook.
   - Pair the right text with the sound and script.
   - Show the lines that keep viewers hooked, and keep them hooked throughout (re-hooks, open loops).
4. **Full-screen animations guide (right)**
   - Three kinds of animation.
   - Four categories: **text-centric, object-centric, character-centric, video-centric**. Each has a description
     covering assets, effects, shapes, placement and construction.
   - Use the example images as references for every animation.
5. **"How to Create Animations" guide (under that)**
   - Build order: background → placement → effects on objects → stylisation.
6. **Inspiration board (left) and on-screen animations (bottom)**
   - The left board holds UIs, graphs and scenes to reference for every animation.
   - For on-screen animations (graphics over the talking head): **darken and blur the background behind the graphic**
     so it reads. Use the right-hand sheet as the reference.

## Existing practice in this repo (One Loop and other reels) that already matches
- Sans heavy caps (Montserrat) plus an italic script/serif accent (Playfair italic) for emotional words.
- The speaker stays on screen in the hook.
- Captions avoid face, eyes, mouth and active hands, inside the 9:16 safe zones.
